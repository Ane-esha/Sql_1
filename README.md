## DDL Commands and Constraints

- This assignment focuses on using SQL Data Definition Language (DDL) commands to recreate an employee database and create
  three tables: "Departments", "Location", and "Employees".

- The project involves defining appropriate primary keys, foreign keys, and constraints to maintain data integrity.
  These include unique identifiers, non-null fields, valid gender values ("M"/"F"), a minimum age of 18, and a default hire date.

 -Additional tasks include altering table structures by adding, modifying, dropping, and renaming columns; renaming tables; 
 truncating the "Employees" table; and finally dropping tables and the database.
